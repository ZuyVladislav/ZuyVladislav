# Политика конфиденциальности

## Playwright MCP Background Bridge for Yandex Browser

Дата редакции: 9 октября 2026 года.

Издатель: Владислав Зюзин. Контакт по вопросам обработки данных: **v.d.zyuzin@gmail.com**.

## 1. Назначение расширения

Расширение соединяет локальный сервер Playwright MCP с отдельным рабочим окном в существующем профиле Яндекс Браузера. Оно передаёт команды подключённого клиента в назначенные ему вкладки и возвращает результаты автоматизации. Область работы включает разные HTTP/HTTPS-сайты, выбранные пользователем для задания.

## 2. Какие данные обрабатываются

В рамках задания расширение может получать и передавать локальному клиенту:

- содержимое назначенных страниц: текст, структуру, изображения, ссылки, снимки страниц и результаты запросов отладки;
- адреса и заголовки страниц автоматизации;
- команды навигации, кликов, ввода и другие действия автоматизации, их параметры и результаты;
- сведения, находящиеся в выбранных страницах, формах или вводимых клиентом значениях.

Если такие сведения присутствуют в задании или открытой странице, обработка может включать идентифицирующую информацию, медицинские сведения, финансовые и платёжные данные, данные для аутентификации, личную коммуникацию и сведения о местоположении. Расширение не содержит универсального фильтра, гарантированно исключающего эти категории из результатов. Наличие разрешений не означает непрерывный сбор данных со всех пользовательских вкладок.

Расширение не использует данные для рекламного профилирования и не содержит отдельного регистратора действий пользователя в посторонних вкладках. Перед выполнением команд проверяется принадлежность целевой вкладки клиенту и рабочему окну.

## 3. Цель использования

Данные используются для выполнения заявленных заданий автоматизации браузера и связанных с этой функцией эксплуатационных задач. JavaScript, полученный от локального Playwright MCP, может выполняться в назначенной веб-странице через chrome.debugger для чтения и взаимодействия с её содержимым. Код самого расширения поставляется в установленном пакете.

## 4. Получатели данных

Расширение связывается с локальным сервером Playwright через WebSocket на loopback-адресе того же компьютера. Служебные сообщения передаются локальной программе com.codex.playwright_background через Native Messaging. В расширении нет отдельного сервера аналитики или сбора данных издателя.

Результаты получает подключённый клиент автоматизации. Этот клиент может передавать их внешним сервисам, выбранным пользователем, включая сервисы обработки заданий и искусственного интеллекта. Получатели, условия обработки и сроки хранения такой передачи определяются используемым клиентом, его настройками и политиками этих сервисов. Расширение не управляет ими и не обещает, что вся цепочка обработки остаётся на компьютере пользователя.

Расширение не отправляет сведения об обработанных страницах в Chrome Web Store. Браузер, сайты и другие установленные программы могут обрабатывать собственные данные по своим политикам независимо от расширения.

## 5. Хранение и удаление

В chrome.storage.session сохраняются идентификаторы рабочего окна, служебной вкладки и сохранённых вкладок. Это состояние ограничено текущей сессией браузера и не синхронизируется через Chrome Sync. Расширение не намерено сохранять содержимое страниц и значения форм в своём постоянном хранилище.

После отключения клиента его вкладки могут оставаться открытыми. История, cookies и данные сайтов в профиле управляются браузером и соответствующими сайтами. Пользователь может закрыть вкладки и очистить данные профиля штатными средствами браузера.

Playwright MCP и подключённый клиент могут сохранять результаты заданий в настроенных ими файлах или сервисах. Удаление расширения не удаляет автоматически эти результаты; их следует удалить средствами соответствующих программ и сервисов.

## 6. Управление доступом

Пользователь может остановить подключённый клиент, завершить соединение, закрыть назначенные вкладки, отключить или удалить расширение. Следует предоставлять доступ только к сайтам и данным, которыми пользователь вправе распоряжаться, и проверять настройки подключённого клиента перед работой с чувствительными сведениями.
